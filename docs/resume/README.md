# AI Engineer Resume

This directory contains the one-page AI Engineer resume source and compiled PDF. The resume is tailored toward AI agent creation, generative AI, RAG, NL-to-SQL, enterprise automation, and production Python engineering.

The project portfolio includes the [Cross-Sell Prediction](https://github.com/Tirumala2824/Cross-sell-prediction) project in place of the earlier demand-forecasting project so the resume highlights both agentic AI and applied machine learning.

## Compile locally

```bash
pdflatex -interaction=nonstopmode ai-engineer-resume.tex
```

The compiled output is intentionally checked in for convenient recruiter review. Quantitative achievements in the resume are drawn from the supplied source content and project documentation; they should be updated if stronger verified measurements become available.
