# AI Engineer Resume

This directory contains the one-page AI Engineer resume source and compiled PDF. The resume is tailored toward agentic planning, Generative AI, advanced RAG, AI automations, fine-tuning exploration, NL-to-SQL, and production Python engineering in Azure-led cloud environments with GCP, AWS, and Snowflake awareness.

The project portfolio features the [Contract Risk Analyzer](https://github.com/Tirumala2824/contract-risk-analyzer) as the principal agentic AI project and the [Cross-Sell Prediction](https://github.com/Tirumala2824/Cross-sell-prediction) project as the applied ML project. The resume avoids repeated metrics and keeps quantitative claims tied to the supplied source material.

## Compile locally

```bash
pdflatex -interaction=nonstopmode ai-engineer-resume.tex
```

The compiled output is intentionally checked in for convenient recruiter review. Quantitative achievements in the resume are drawn from the supplied source content and project documentation; they should be updated if stronger verified measurements become available.
