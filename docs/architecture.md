# Profile Repository Architecture

This repository is the public GitHub profile surface rather than a deployable application. Its primary artifact is `README.md`, which presents verified projects, engineering focus, lifecycle distinctions, and collaboration expectations.

The profile README is intentionally separate from project repositories. It should link only to repositories that exist in the account, identify private work without exposing sensitive details, and describe older learning or academic work as history rather than production software.

Changes to the profile should be reviewed for link accuracy, factual consistency, clarity, and alignment with the shared engineering standards.
